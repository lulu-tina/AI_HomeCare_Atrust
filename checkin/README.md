# CareFlow 居服員打卡

居服員用手機打卡，不用安裝 App、不用密碼：掃 QR Code → 第一次輸入員工編號（這支手機就綁定給他）→
看到今天的案家 → 到了按「到勤打卡」、離開按「離開打卡」，系統記下時間和位置。之後打開就直接是今天的班。
督導在 CareFlow「04 排班結果與覆核 › 📱 居服員打卡」看今日打卡看板，整段期間的遲到、缺卡在「執行對照」。

## 督導每天怎麼做（都在 CareFlow 04 頁，不用開指令視窗）

1. **給網址**：按 ①「🌐 產生外部網址」，把 QR Code 圖片傳到 LINE 群組或印出來。
2. **發布班表**：排好班後按 ②「📲 發布目前班表」。有代班、改期再按一次。
3. **手機**：居服員第一次輸入員編，第一支手機自動綁定。**換手機**時 04 頁會跳出「🔔 新手機等你核准」，按 ③ 的「核准」。
   手機遺失、離職、綁錯人：③「已綁定的手機」解除綁定。
4. **看打卡**：④ 今日打卡看板。🔴 逾時未到勤＝過了開始時間 15 分鐘還沒打卡，可打電話確認；📍 地圖＝打卡時手機的位置。

打卡網頁會跟著 CareFlow 一起啟動（同一台電腦、port 8600），不用再另外開 `start_checkin.bat`。

## 兩種用法

| | 辦公室試用 | 正式上線 |
|---|---|---|
| 網址 | 04 頁自動顯示 `http://這台電腦IP:8600` | 資訊人員設定的 `https://checkin.你的網域` |
| 誰打得開 | 只有連同一個 Wi-Fi 的手機 | 居服員在外面用行動網路也能打 |
| 定位 | 手機不給（打卡標「無定位」） | 有 |
| 需要做的事 | 什麼都不用 | 資訊人員做一次（下面） |

## 正式上線（資訊人員，做一次）

手機只有在 **https** 網址下才會給定位，所以要一個固定網域。用專案附的 Docker 設定最簡單：

1. 準備一台雲端主機（或機構內一直開著、可對外的電腦），裝好 Docker。
2. DNS 加兩筆指到這台主機：`careflow.你的網域`（督導用）、`checkin.你的網域`（居服員打卡用）。
3. 改 `deploy/Caddyfile` 兩個網域、督導帳密雜湊；改 `docker-compose.yml` 的 `CAREFLOW_CHECKIN_PUBLIC_URL`。
4. `docker compose up -d --build`。Caddy 會自動申請 https 憑證。
5. 督導打開 CareFlow 04 頁，QR Code 就會是固定網址（也可以在「進階：設定固定打卡網址」直接貼上）。

沒有網域、只想先讓外面的手機試用：安裝 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)，
執行 `cloudflared tunnel --url http://localhost:8600`，把它給的 `https://….trycloudflare.com` 貼到 04 頁「進階」。這個網址每次重開都會變，只適合試辦。

## 資料與個資

- 手機只顯示案號和遮罩後的案家名稱（王○明），不顯示地址、電話、健康資料。
- 打卡時間用主機時間，不用手機時間。打卡紀錄只能新增不能修改；更正用「補登」（標成補卡待審，不記位置）。
- 不用密碼，改用「手機綁定」：手機只存一組隨機代碼，資料庫只存它的雜湊。一人一支手機；換手機要督導核准，核准後舊手機立刻失效。
- 第一支手機自動綁定的風險：如果有人先用別人的員編綁定，本人登入時會變成「待核准」，督導會發現。推行初期請看一下 ③「已綁定的手機」名單；
  要更嚴格可以關掉「第一支手機自動綁定」，每支手機都由督導核准。
- 打卡資料在 `output_results/checkin.sqlite3`，請和其他排班資料一起備份。保存年限依機構規定（見 DATA_GOVERNANCE.md）。
- GPS 可能被偽造；距離異常只當提醒，不當懲處依據。

## 進階設定（環境變數）

| 變數 | 用途 |
|---|---|
| `CAREFLOW_CHECKIN_PUBLIC_URL` | 固定打卡網址（04 頁「進階」設定的優先） |
| `CAREFLOW_CHECKIN_AUTOSTART=0` | 不要跟著 CareFlow 啟動（打卡網頁另外架在別台時） |
| `CAREFLOW_CHECKIN_PORT` | 埠號，預設 8600 |
| `CAREFLOW_CHECKIN_DB` | 資料庫位置 |
| `CAREFLOW_CHECKIN_SECURE=1` | 登入 cookie 只走 https（正式上線建議開） |

指令工具（`python -m checkin.manage …`）的 PIN 功能是舊版留下的，打卡網頁已改用手機綁定，不再需要 PIN。

## 目前的限制

- 沒有離線打卡：收不到訊號時要有網路再按，或事後「補登」。
- 只能打「今天、發布給自己」的班；臨時代班要督導先改班表並重新發布。
- 一台主機、SQLite，約幾十位居服員同時使用沒問題；規模再大要換正式資料庫。
